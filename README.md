# Video Studio — releases

Installers and automatic updates for Video Studio.

- **macOS (Apple Silicon):** download `VideoStudio-<version>-mac-arm64.dmg` from the latest release. The app is not signed with an Apple Developer ID, so if macOS refuses to open it: System Settings → Privacy & Security → Open Anyway.
- **Windows (x64):** download `VideoStudio-<version>-win-x64.exe`. Windows SmartScreen may warn about an unknown publisher: More info → Run anyway.

After installation the app updates itself.
